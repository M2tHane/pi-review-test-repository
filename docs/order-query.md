# 订单查询与导出

运营面板按订单加入目录的顺序展示记录；导出文件按订单号排序。导出操作不应改变运营面板随后看到的顺序。

例如，先加入 `ORDER-102`，再加入 `ORDER-101`：导出内容按 `ORDER-101`、`ORDER-102` 排列；再次调用 `listOrders()` 时仍按 `ORDER-102`、`ORDER-101` 展示。

此模块是治理服务完整流程的独立演示数据，使用单线程顺序调用，不连接真实订单系统。

## 列表查询契约

`backend/walkthrough/orders/` 的对外列表查询返回不可修改的时间点快照。调用方不能修改返回值，目录之后加入新订单也不能改变此前已经返回的结果。

查询使用 `List.copyOf` 固定内容；导出先复制到自己的 `ArrayList` 中排序，再返回不可修改的快照。只用 `Collections.unmodifiableList` 包装内部集合仍然会随着内部写入变化，不满足时间点快照契约。
